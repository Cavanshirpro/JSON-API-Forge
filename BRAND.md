# Editor brand and naming policy

The Editor uses the Amber Gold + Graphite Gray palette derived from the
canonical JSON API Forge logo.

- `editor/resources/logo.png` is the full background logo. Use it for the
  application, window, desktop and installer icons.
- `editor/resources/brand-mark-transparent.png` is the transparent,
  text-free mark. Use it only inside the application where the full badge
  would be visually heavy.
- Keep both assets' aspect ratio and alpha channel intact. Do not recolor,
  stretch, outline or place the transparent mark on a low-contrast surface.
- The primary interface colors are Amber Gold `#f2b84b` and Graphite Gray
  `#202225`; accessible lighter/darker tones may be used for state and depth.

The source-code license does not grant trademark or branding rights. You may
truthfully state that a service uses or is compatible with JSON API Forge, but
you may not imply that an unofficial fork, product or distribution is an
official release or has sponsorship without written permission.
