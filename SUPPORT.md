# Support

JSON API Forge is provided without a support warranty.

For normal usage questions, configuration questions, documentation corrections and reproducible bugs, use the canonical repository's issue tracker when available. Search existing issues before opening a new one and include the JSON API Forge version, Python version, deployment mode, relevant configuration with secrets removed, and a minimal reproduction.

For security vulnerabilities, follow `SECURITY.md` and do not publish credentials or exploit details in a public issue.

For redistribution, OEM, alternative licensing or permission to publish a derivative distribution, you need separate written authorization from the Project Owner; an ordinary issue or pull request does not itself grant such permission.
